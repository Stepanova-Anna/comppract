# Лабораторная работа № 4. Основы работы с SoapUI - старые SOAP сервисы
**Цель проекта:** Создание проекта с применением открытых публичных SOAP сервисов. Разработка и реализация автоматизированного теста для проверки функциональности публичного SOAP сервиса “Country Info Service” с использованием SoapUI.

*Бизнес-процесс:*
Получение информации о стране – «United Stated» (Получение кода страны; название страны по ее коду; столицы; флаг; валюты по ее коду; страны, использующие эту валюту)

# Лабораторная работа 11
### Задание

Напишите корневой адрес работающего по https веб-приложения и ссылку на гитхаб-репозиторий с кодом и отчетом-демонстрацией работы приложения, которое по маршруту /decypher получает в формате multipart/form-data приватный ключ для расшифровки (имя поля формы key) и зашифрованное содержимое (имя поля формы secret) и выдаёт в виде обычной строки результат расшифровки.
Требования к решению: 

1. Фреймворк Flask или FastAPI или любой другой Python-framework (микро-фреймворк - без развесистой структуры файлов и папок внутри).
2. Формат ответа по маршруту /login {"author": "__ваш логин__"}
3. Реализация дополнительных решений более чем с 1 фреймворком (варианты: Node.js, Django, Go).
4. Реализация фронтэнда и отправка данных на сервер с использованием какого-либо фронтэнд-фреймворка или библиотеки (Vue.js, Svelte, React).
5. Вывод и отображение исходного текста на страницу с формой (без перезагрузки страницы, асинхронно).

---

### Решение
Задание было выполнено в Replit. Однако в бесплатной версии увидеть работу приложения в онлайн режиме не предоставляется возможным

[Ссылка на борд в replit](https://35a7dc61-8248-49cb-ae19-e9b0e6ffead4-00-314ild94szqgw.sisko.replit.dev/)

Приложение созданное с помощью Flask, выполняет следующее:

1. Пользователь открывает основную страницу (/):
- Загружаются два файла: приватный ключ (key) и зашифрованное сообщение (secret).
2. Выбор файлов:
- Через специальную форму на главной странице пользователь выбирает два файла.
3. Отправка данных на сервер:
- Нажимая кнопку «отправить», пользователь передает файлы на сервер через POST-запрос по адресу /decypher.
4. Обработка на сервере:
- Сервер получает файлы, считывает их содержимое и передает на обработку функции decrypt_message().
- Функция decrypt_message() расшифровывает зашифрованное сообщение с помощью алгоритма Fernet из библиотеки cryptography.
5. Возврат результата:
- Если расшифровка прошла успешно, сервер возвращает результат в виде обычного текста.
- В случае ошибки выдается сообщение об ошибке с указанием причины.
6. Дополнительные маршруты:
- Маршрут /login возвращает JSON с информацией о пользователе.

---

Отдельный модуль `gen_key` выполняет следующее:
1. Генерация ключа шифрования:
- Библиотека cryptography помогает сгенерировать уникальный симметричный ключ, подходящий для алгоритма Fernet. Симметричное шифрование подразумевает, что один и тот же ключ используется как для шифрования, так и для расшифровки данных.
2. Шифрование сообщения:
- Создается объект класса Fernet, которому передается созданный ключ.
- Исходное сообщение ("Hello, World!") преобразуется в байтовый массив (b"...") и шифруется с помощью метода .encrypt().
3. Вывод результата:
- Программа печатает сгенерированный ключ и зашифрованное сообщение в удобочитаемом виде.
4. Сохранение данных:
- Оба файла — ключ (key.txt) и зашифрованное сообщение (secret.txt) — сохраняются на диск в бинарном формате (wb — write binary).
